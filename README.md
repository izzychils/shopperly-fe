# lunchpaad-fe

Shopperly - AI-Powered Website Builder -> lunchpaad - AI-Powered Website Builder

A modern, responsive landing page for an AI-powered website builder platform built with React, TypeScript, and Vite.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## ✨ Features

- 🎨 Modern, clean design matching the inspiration images
- 📱 Fully responsive for mobile, tablet, and desktop
- ⚡ Built with Vite for lightning-fast development
- 🔷 TypeScript for type safety
- 🎭 Smooth animations and transitions
- 🧩 Component-based architecture with organized folder structure

## 🛠️ Tech Stack

- **React 18.2** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **Lucide React** - Icon library
- **CSS3** - Styling
