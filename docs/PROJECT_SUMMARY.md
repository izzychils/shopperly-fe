## 🚀 Getting Started

### Quick Start (3 Commands)

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Open http://localhost:5173
```

### Build for Production

```bash
npm run build
```

Output will be in `dist/` folder, ready to deploy!

## 🐛 Troubleshooting

### Common Issues

**Port in use?**

```bash
rm -rf node_modules
npm install
```

**Build fails?**
```bash
npm run build -- --clearCache
```
